# 📱 Signup & Login Android App

A simple and clean Android application that provides **User Signup, Login, and Welcome Dashboard** using Firebase.

---

## 🚀 Features

* 🔐 User Signup (Create Account)
* 🔑 User Login Authentication
* 👋 Welcome Page after Login
* 🔥 Firebase Integration
* 📄 User Details Display on Welcome Screen
* ⚡ Simple and User-Friendly UI

---

## 🛠️ Technologies Used

* **Java / Kotlin (Android)**
* **Firebase Authentication**
* **Firebase Realtime Database**
* **Android Studio**

---

## 📂 Project Structure

* `Signup Activity` → Create new account
* `Login Activity` → User authentication
* `Welcome Activity` → Display user data
* `Firebase` → Store and retrieve user details

---

## 🔥 Firebase Setup

This app uses Firebase for authentication and storing user data:

* User credentials stored securely
* User details fetched and shown on Welcome screen

---

## 📸 Screens (Overview)

* Signup Page
* Login Page
* Welcome Dashboard

---

## 💡 How It Works

1. User creates account using Signup
2. Data is stored in Firebase
3. User logs in using credentials
4. App verifies using Firebase Authentication
5. Welcome page shows user details
